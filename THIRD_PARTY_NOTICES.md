# Third-party notices and license checklist

No third-party source files, translation databases, fonts, or model weights are bundled in this starter repository.

## Research candidate: wodzys/dwarf-fortress-chinese

- Repository: https://github.com/wodzys/dwarf-fortress-chinese
- The upstream repository metadata lists MIT for the code.
- The upstream Chinese translation data is separately licensed; do not copy it into this project unless the applicable license explicitly permits the intended use.
- Before porting source files, preserve the MIT copyright and license notice, document modified files, and confirm current upstream license files.

## Before first binary release

- [ ] Record exact upstream URL and commit/tag.
- [ ] Include license text and attribution for every reused source file.
- [ ] Audit all dictionary rows and translations for provenance and license.
- [ ] Verify font redistribution rights and include notices.
- [ ] Record licenses for each optional translation model and model dependency.
- [ ] Do not commit API keys, private endpoints, save files, or private test logs.
- [ ] Choose and publish a license for this repository after the source and data audit.
