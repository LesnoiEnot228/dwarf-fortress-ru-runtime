# Dwarf Fortress RU Runtime

> Русификация отображаемого текста Dwarf Fortress во время игры на базе DFHack.

**Статус:** bootstrap / исследовательский прототип. Это пока не готовый игровой плагин и не проверенная Windows-сборка.

## Цель

- Переводить интерфейс, предметы, описания, хроники, диалоги, мысли, книги и строки совместимых модов.
- Обрабатывать составные и процедурно созданные названия через словари и правила.
- Переводить неизвестные фразы асинхронно с кэшированием.
- Транслитерировать незнакомые имена, учитывая словарные исключения.
- Не изменять сохранения ради локализации.
- Собирать непереведённые строки и улучшать переводы без выпуска нового бинарного файла.

## Начало работы

1. Запишите точную версию Dwarf Fortress (Steam → свойства/версия игры) и версию DFHack (`help`/команда версии в консоли DFHack).
2. Сверьте совместимость выбранной основы с этой парой версий.
3. Установите инструменты сборки, требуемые именно вашей веткой DFHack.
4. Сначала собирайте и тестируйте на копии мира или резервной копии сохранений.

В этой заготовке **нет DLL и работающего C++-перехватчика**. Плагин должен собираться против подходящих заголовков и библиотек установленной версии DFHack. Не загружайте бинарник от другой версии.

## Исследуемая основа

В качестве исследовательской основы рассматривается [wodzys/dwarf-fortress-chinese](https://github.com/wodzys/dwarf-fortress-chinese), C++/DFHack-плагин с MIT-лицензией на исходный код. Код, уведомления и лицензии нужно соблюдать при любом заимствовании. Переводческие данные этого проекта не копируются: они имеют отдельную лицензию. Русские данные создаются самостоятельно либо добавляются после проверки разрешения.

## Ограничения

Не каждый экран использует один и тот же механизм отрисовки. Поэтому нельзя обещать перевод всего отображаемого текста до аудита конкретной версии игры и тестов. Новая фраза может временно остаться на английском, пока фоновый переводчик не вернёт результат. Сетевой перевод по умолчанию должен быть выключен; строки нельзя передавать внешним сервисам без явного согласия пользователя.
