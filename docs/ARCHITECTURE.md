# Архитектура

## Принципы

1. Переводится текст на границе отображения, а не мир, игровые объекты или сохранения.
2. Вызов отрисовки не ждёт диска, сети или модели машинного перевода.
3. Данные перевода отделены от C++-плагина.
4. Неизвестная строка безопасно остаётся оригинальной до получения перевода.
5. Провайдер перевода сменный; секреты внешнего API не хранятся в репозитории.
6. Строки с управляющими символами, форматными вставками и цветовыми тегами обрабатываются с сохранением разметки.

## Поток обработки

```text
Dwarf Fortress UI
  -> совместимый с версией DFHack адаптер отображения
  -> нормализация строки и выделение защищённых токенов
  -> точный словарь
  -> правила составного/процедурного текста
  -> локальный кэш
  -> асинхронная очередь перевода (если разрешена)
  -> кэш и журнал непереведённых строк
  -> отрисовка перевода с оригинальным форматированием
```

## Компоненты

- `plugin/` (будущий C++): интеграция с API DFHack, управление настройками и безопасное отображение.
- `translation/dictionaries/`: точные переводы UTF-8 CSV/JSON.
- `translation/rules/`: правила составных названий и транслитерации. Правила должны иметь тесты и однозначный приоритет.
- `translation-worker/` (будущий компонент): фоновая очередь, дедупликация, таймауты, ограничение скорости и сменные локальные/сетевые адаптеры.
- `cache/` (будущее runtime-хранилище вне каталога сохранений): кэш, привязанный к версии схемы и провайдера.
- `tests/`: unit-тесты лексики/токенов/правил и fixture-наборы извлечённых строк.

## Приоритет обработки

1. Пропустить пустую или управляющую строку без изменений.
2. Защитить форматные маркеры, числа, имена файлов, ссылки и игровые placeholders.
3. Точное совпадение в словаре.
4. Правило составного текста.
5. Кэш машинного перевода.
6. Отложить неизвестный фрагмент в очередь, только если пользователь включил провайдера.
7. Вернуть исходную строку до завершения задания.

## Сегментация

Нельзя переводить каждую отрисовываемую часть отдельно без контекста: это может повредить грамматику, цвета и ссылки на сущности. Адаптер должен по возможности объединять фрагменты в смысловую единицу, а защищённые токены возвращать в прежние позиции. Если сегментация ненадёжна, оставлять строку без автоматического перевода и записывать диагностический пример.

## Имена

- Сначала использовать исключения из словаря.
- Неизвестные собственные имена передавать в отдельную транслитерацию, а не в общий машинный перевод.
- Не транслитерировать известные системные термины, коды, числовые идентификаторы и placeholders.
- Результат транслитерации кэшировать, но позволять пользователю исправить его словарём.

## Безопасность и приватность

- Сетевые провайдеры по умолчанию выключены.
- Внешнему провайдеру отправляется только выбранный текст, без сохранений и без лишнего игрового контекста.
- В логах не сохранять секреты API.
- Ошибка провайдера не должна ломать интерфейс или игру.
- Настройки, кэш и журналы размещать вне каталогов сохранений, насколько позволяет API целевой платформы.
