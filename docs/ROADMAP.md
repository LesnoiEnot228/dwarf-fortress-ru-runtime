# Дорожная карта

## Этап 0 — фиксация версии и аудит основы

- [ ] Зафиксировать версии Steam Dwarf Fortress и DFHack.
- [ ] Проверить API плагинов и процесс сборки для этой версии.
- [ ] Проверить активную ветку/релиз dfzh, статус поддержки и ограничения лицензий.
- [ ] Собрать оригинальный прототип до изменения поведения.
- [ ] Зафиксировать baseline: запуск, частота кадров, логи, отображение кириллицы.

**Приёмка:** прототип собирается против нужной версии и безопасно загружается в тестовом мире.

## Этап 1 — минимальный русский UI

- [ ] Кириллический шрифт и проверка ширины глифов.
- [ ] Словарь базовых меню и часто встречающихся системных строк.
- [ ] Включение/выключение перевода без изменения сохранения.
- [ ] Правильное сохранение цвета, переносов и placeholders.

**Приёмка:** выбранный набор экранов отображается корректно на русском; английский fallback работает.

## Этап 2 — динамические названия

- [ ] Схема словаря и валидация CSV/JSON.
- [ ] Правила составных названий предметов, материалов, свойств и существ.
- [ ] Словарные исключения и транслитерация имён.
- [ ] Fixtures для случайно сгенерированных комбинаций.

**Приёмка:** новые сочетания знакомых компонентов переводятся без добавления каждой полной строки в словарь.

## Этап 3 — гибридный перевод

- [ ] Интерфейс провайдера перевода.
- [ ] Фоновая очередь, объединение дублей, отмена устаревших заданий и таймауты.
- [ ] Локальный переводчик как первый необязательный адаптер после сравнения моделей.
- [ ] Внешний адаптер только по явному согласию пользователя.
- [ ] Кэш, миграция схемы, лимиты размера и управление очисткой.

**Приёмка:** неизвестный текст не блокирует UI; ошибка/отсутствие провайдера не вызывает сбой.

## Этап 4 — длинные тексты и моды

- [ ] Хроники, истории, мысли, книги и надписи.
- [ ] Группировка строк по смысловым блокам с сохранением разметки.
- [ ] Сбор непереведённых строк и экспорт для редакторов.
- [ ] Пробный набор известных пользовательских модов.

**Приёмка:** опубликован отчёт покрытия и список ограничений по каждому типу текста.

## Этап 5 — стабильность и публикация

- [ ] Тесты производительности с холодным/тёплым кэшем.
- [ ] Тест длительной работы и отключённого интернета.
- [ ] Windows-сборка, хэши артефактов и CI.
- [ ] Установка/обновление/отключение/удаление по инструкции.
- [ ] Проверка лицензий кода, данных и шрифтов.
- [ ] Подготовка отдельного пакета для Steam Workshop после стабильного релиза.

**Приёмка:** сборка и инструкция воспроизводимы для указанной версии DFHack.
