# Разработка

## Что нужно уточнить перед компиляцией

- Точная версия Dwarf Fortress из Steam.
- Версия DFHack, установленная для этой версии игры.
- Какой компилятор и зависимости требуют исходники выбранной версии DFHack.

DFHack — нативная интеграция, чувствительная к версии. Не использовать DLL от другой версии игры/DFHack.

## Рекомендуемый рабочий процесс

1. Проверить совместимость текущих исходников DFHack и исследуемой основы с нужной парой версий.
2. Создать ветку `feat/dfhack-prototype`.
3. Зафиксировать upstream и точный commit/tag исследуемой основы в документации.
4. Сначала добиться чистой сборки без изменений; только затем менять код.
5. Не переносить сторонние словари без проверки лицензий.
6. Каждую функцию сопровождать тестами и описанием совместимых версий.

## Проверка данных

```powershell
python -m unittest discover -s tests -v
```

Пока C++-адаптер не реализован, документы и тестовые данные не следует выдавать за готовый игровой мод.
